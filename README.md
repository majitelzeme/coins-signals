# Memecoin Signals

Static installable web app that ranks memecoins by live technical buy and sell signals. The list comes from the CoinGecko `meme-token` category. If CoinGecko is unavailable, the app falls back to memecoin USDT pairs on Binance. There is no build step; GitHub Pages serves these files as-is.

The signals are technical indicators (RSI, moving averages, MACD, and momentum) computed from past prices. They are not financial advice. Memecoins are extremely volatile.

Published site: https://majitelzeme.github.io/coins-signals/

## Install on a phone

Open the site in the phone’s browser, then:

- Android: Chrome menu > Install app / Add to Home screen
- iOS: Safari Share > Add to Home Screen
